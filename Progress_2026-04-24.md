### Implementation Details

#### 1. HTML Structure (`index.html`)
```html
<!-- NB Monogram Background Letters - Fixed across entire page -->
<div class="nb-monogram-bg">
    <span class="nb-letter-n">N</span>
    <span class="nb-letter-b">B</span>
</div>
```
- Placed at body level (before services section)
- Wrapped in container div for positioning control

#### 2. CSS Styles (`css/styles.css`)

**Container (.nb-monogram-bg):**
- `position: fixed` - stays in place while scrolling
- Full viewport coverage (100% width/height)
- `z-index: 1` - above background, below content
- `pointer-events: none` - doesn't block interactions

**Letters (.nb-letter-n, .nb-letter-b):**
- Font: Poppins, 900 weight, 45vw size
- Color: `rgba(255, 255, 255, 0.08)` - subtle white
- N positioned left (-5%), B positioned right (-5%)
- Both vertically centered (top: 50%)

#### 3. Animations

**floatN (N letter):**
```css
@keyframes floatN {
    0%, 100% { transform: translateY(-50%) translateX(0); }
    50% { transform: translateY(-40%) translateX(5%); }
}
```

**floatB (B letter):**
```css
@keyframes floatB {
    0%, 100% { transform: translateY(-50%) translateX(0); }
    50% { transform: translateY(-60%) translateX(-5%); }
}
```
- Duration: 8 seconds
- Timing: ease-in-out infinite
- B has -4s delay for offset/staggered effect

#### 4. Responsive Breakpoints

| Breakpoint | Font Size | Opacity |
|------------|-----------|---------|
| Desktop | 45vw | 8% |
| 768px (Tablet) | 50vw | 6% |
| 480px (Mobile) | 55vw | 5% |
